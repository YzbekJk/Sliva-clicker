# Слива кликер

Кликер про сливы: жмёшь на сливу, покупаешь садовников, деревья и фабрики. Прогресс сохраняется, а пока игра закрыта, сады приносят до 2 часов дохода.

Игра — один файл `app/src/main/assets/index.html`. Android-приложение — оболочка WebView, которая его открывает.

## Как получить APK

### Вариант 1. GitHub (без установки чего-либо)
1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки (включая скрытую папку `.github`).
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow** (сборка также запускается сама при каждом пуше).
3. Через 2–4 минуты внутри завершённого запуска, в разделе **Artifacts**, появится `sliva-clicker-apk`. Скачайте, распакуйте, получите `app-debug.apk`.

### Вариант 2. Android Studio
Откройте папку как проект → **Build → Build APK(s)**. Файл будет в `app/build/outputs/apk/debug/`.

## Установка на телефон
Скопируйте `app-debug.apk` на телефон и откройте. Если Android попросит, разрешите установку из этого источника.

## Играть без APK
Откройте `app/src/main/assets/index.html` в любом браузере.
