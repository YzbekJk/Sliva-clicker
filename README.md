# Kussia88 кликер

Кликер: жмёшь на стримера, и он выдаёт случайный мем-ролик со звуком. За клики и пассивный доход покупаются улучшения. Прогресс сохраняется.

Игра — один файл `app/src/main/assets/index.html`, клипы лежат в `app/src/main/assets/clips/` (`m01.mp4`, `m02.mp4`, …). Android-приложение — оболочка WebView.

## Как добавить свои клипы
1. Положите файл в `app/src/main/assets/clips/` под следующим номером (`m16.mp4`). Формат: H.264 + AAC, примерно 480×280.
2. В `index.html` увеличьте `CLIPS`.
3. Запушьте — APK соберётся сам (вкладка Actions).

## APK
Сборка запускается при каждом пуше в `main`. Готовый APK выкладывается на сайт (GitHub Pages) и доступен как артефакт запуска.
